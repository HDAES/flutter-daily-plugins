## 中文主帖草稿

今天写了个 Flutter 密码强度提示组件 🔐

输入时能实时显示长度、大小写、数字和符号是否满足，还带进度条。核心逻辑独立成 Dart 评估器，方便写测试。

目前源码已开源，准备在 Mac 上实际跑一遍再补效果图。密码强度提示≠密码真正安全。

源码：https://github.com/HDAES/flutter-daily-plugins/tree/main/day-004-password-strength-meter

## 技术总结

- 将纯 Dart 规则评估器与 Flutter UI 分离。
- 长度不足时不显示“良好”或“强”；进度条仅表示规则覆盖率。
- Widget 不存储密码、不发网络请求；真实密码安全仍由服务端策略保障。
- 兼容性、性能和无障碍体验需在目标设备上验证。
