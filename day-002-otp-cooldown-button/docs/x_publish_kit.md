## 技术总结与可以分享的观点

- `setState` 在调用异步发送前同步上锁，避免短时间重复触发。
- 成功后启动倒计时、失败后解锁，明确区分客户端体验与服务端发送结果。
- 后台定时器可能暂停，回前台时用时间戳重新计算剩余时间。
- UI 倒计时只是体验层，**服务端限流和验证码风控才是安全边界**。
